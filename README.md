# Bayesian-Inference-and-Data-Assimilation-Using-Kalman-Filtering
Implements Bayesian data assimilation using a state-space model and Kalman filtering to analyse agricultural price data. It focuses on estimating hidden states and uncertainty over time, with results visualised through trajectory plots and credible intervals. Implemented in MATLAB.
